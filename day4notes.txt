JVM-----Java Virtual Machine-----Converts java byte code(compiled code) into runtime instructions.

Scala runs on JVM.

Since spark is written in scala, you need a jvm to run it.

For working with unstructured data, spark core apis are used.
Spark core apis uses RDD-----Resilient Distributed Dataset

For working with structured data like csv,json,avro,parquet and rdbms, it uses dataframes.

RDD is the fundamental unit of data in Spark.




R-----Resilient-------if data is lost,  it  can be recovered.
D----Distributed----data is divided into partitions across multiple machines
D----Dataset-------collection of data elements

RDD is used to process large amounts of data across multiple machines in a cluster.

glom()----groups all elements of each partition into a python list.
