Python:

Higher level, general purpose programming language known for its simple syntax and readability.

3 Programming Paradigms:

1. Procedural Programming

2. Object Oriented Programming

3. Functional Programming

Procedural Programming:

Follows a top down approach. One main function calls the subroutines or other functions to achieve a  task.

Examples: C, Fortran, Pascal


Object Oriented Programming:

Real world components are modelled as objects.

Any real world component has state and behavior.

If person is a real world component, name and age are examples of state and speaking and walking are examples of behaviours.

state-----data
behaviour---method(function)

Data and methods are encapsulated in a class.

Instance of a class is called an object.

Examples: C++, Java, C#

Functional Programming:

A function is treated as a value or expression.


Functional programming supports:

1. passing a function as an argument to another function.

2. a function can return another function.

3. anonymous functions (functions without a name).

4.  Supports nested functions.

Examples: Scala, Python, Groovy



Rules for python variables:

A variable must with a alphabet or underscore.
A  variable can't start with a number.
A variable name can only contain alphabets, numbers and _.
Variables names are case sensitive.
